# Unmix v0.1.1 — начало работы

Это рабочий прототип записи задач и пересборки проекта для Codex.

## Что уже работает

- Запись задачи: намерение, изменения, зависимости и команды проверок.
- Создание отдельного варианта проекта без выбранной задачи.
- Остановка на конфликтах и зависимостях, требующих адаптации.
- Инструкции для Codex, продолжение после адаптации и проверка результата.
- MCP-сервер с девятью инструментами.

## Запуск

Нужны Node.js 22+ и Git. В папке проекта:

```sh
npm test
npm run demo
```

Демонстрация создаёт тестовый магазин, записывает пять задач и удаляет
регистрацию. Дизайн, оплата, исправление округления и экспорт чека сохраняются.
Исправления в этой демонстрации написаны заранее; вызова живого Codex нет.

## Подключение к Codex

Подставь реальные абсолютные пути:

```sh
codex mcp add unmix -- node /путь/к/unmix/bin/unmix.mjs mcp --repo /путь/к/твоему-проекту
```

Перезапусти Codex и проверь `/mcp`. Добавь инструкции из `docs/codex.md`
в существующий `AGENTS.md` целевого проекта. Сначала используй небольшой
тестовый репозиторий с начальным коммитом.

## Граница готовности

Протокол MCP и пересборка проверены тестами. Настоящий Codex CLI записал четыре
задачи блокнота через MCP и сам адаптировал три сохранённые задачи после удаления
обязательного автора. Пять команд проверки прошли; исходный проект и сохранённые
тесты не изменились. Это один синтетический сценарий, не гарантия для любых проектов.
См. `docs/live-codex.md` и `node examples/live-codex.mjs /absolute/new-directory`.
Смысловую
адаптацию выполняет агент или человек; Unmix организует процесс и хранит
доказательства. Успех проверок относится только к проверенным сценариям.

Исходники лицензированы по MIT. Публичного репозитория и GitHub-релиза пока нет.
В архив включён `unmix-history.bundle` с исходной историей и тегами `v0.1.0`, `v0.1.1`.
Если нужно восстановить Git-репозиторий из него:

```sh
git clone unmix-history.bundle unmix-repository
```
